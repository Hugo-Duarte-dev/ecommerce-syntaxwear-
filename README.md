# SyntaxWear E-commerce

![SyntaxWear Logo](src/assets/img/Logo.svg)

Um projeto de front-end estático que simula a página inicial de um e-commerce de calçados fictício, a SyntaxWear. Este projeto foi desenvolvido utilizando apenas HTML5 e CSS3, com foco em criar uma interface de usuário moderna e responsiva para uma loja de sneakers online.

## 🚀 Como Visualizar

Como este é um projeto estático, não há necessidade de instalação de dependências ou de um servidor complexo. Basta seguir os passos:

1.  Clone este repositório para a sua máquina local.
2.  Abra o arquivo `index.html` diretamente no seu navegador de preferência (Google Chrome, Firefox, etc.).

E pronto, a página estará visível!

## ✨ Funcionalidades

O projeto implementa a página inicial do e-commerce, incluindo as seguintes seções:

*   **Cabeçalho (Header):** Com logo, navegação principal (Masculino, Feminino, Outlet), links secundários e ícones de perfil, ajuda e carrinho.
*   **Seção Hero:** Um banner principal de destaque com título e botões de chamada para ação (CTA).
*   **Categorias:** Cards visuais para as principais categorias de produtos (Casual, Esporte, Moderno, Futurista).
*   **Grid de Produtos:** Uma seção estilizada para exibir produtos em destaque.
*   **Rodapé (Footer):** Com links de navegação, inscrição para newsletter e ícones de redes sociais.

## 📂 Estrutura de Arquivos

O projeto está organizado da seguinte forma para manter o código limpo e modular:

```
ecommerce-syntaxwear/
├── index.html                # Arquivo principal da página
├── README.md                 # Este arquivo
└── src/
    ├── assets/               # Contém todos os recursos visuais
    │   ├── icons/            # Ícones SVG utilizados na interface
    │   └── img/              # Imagens, logos e banners
    └── css/                  # Contém as folhas de estilo
        ├── base/             # Estilos globais e de componentes base
        │   ├── base.css
        │   ├── footer.css
        │   ├── header.css
        │   ├── hero.css
        │   ├── product-grid.css
        │   ├── reset.css
        │   └── variables.css
        └── product-category.css  # Estilos para páginas de categoria
```

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Para a estruturação semântica do conteúdo.
*   **CSS3:** Para estilização, layout (Flexbox/Grid) e responsividade.

Nenhum framework de CSS ou biblioteca JavaScript foi utilizada neste projeto, sendo um exemplo puro de HTML e CSS.
